## What is a database connection?

A database connection is a link between your app and Supabase (cloud database).
Without it, the app has no data to show. Like a phone line: one end dials, the other end answers.

## How it works (flow)

1. You open the app (http://127.0.0.1:8000)
2. Laravel boots and reads .env
3. It takes DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME, DB_PASSWORD
4. It opens a connection to Supabase (via Supavisor Pooler, port 6543)
5. It runs queries (SELECT ... FROM products)
6. Results are shown in the browser
7. When you save, data goes back to Supabase

## Your actual config

DB_CONNECTION=pgsql
DB_HOST=aws-0-ap-northeast-1.pooler.supabase.com
DB_PORT=6543
DB_DATABASE=postgres
DB_USERNAME=postgres.vxmyfozpixzbobwnfziq
DB_PASSWORD=(hidden)
DB_SSLMODE=require

Meaning:
- pgsql = use PostgreSQL
- pooler host = queue for connections (safer under many users)
- 6543 = Transaction pooler port (5432 is for direct)
- SSL require = encrypted connection

## Why pooler?
Direct mode (db.xxx.supabase.co:5432) needs IPv6. Most PH networks are IPv4,
so the pooler is the safe choice. It also handles many users at once.

# FILIPINO

Ang database connection ang tugon ng iyong app sa Supabase.
Ito ang paraan para makuha at ma-save ang lahat ng datos (products, suppliers, sales).
Kung walang connection, walang makikitang datos. Katulad ng telepono: isang duma-dial, isa nga sumasagot.
Bubuksan mo ang app, babasa ng .env, mag-connect sa Supabase, kumuha ng data, ipapakita sa screen.
Kapag ka mag-save, balik na yon sa database. Simple lang, yun lang.
Ang pooler ay parang teller sa bank: nagsasaad ng turn, isa-isa, para hindi ma-overload.
Ang SSL ay parang naka-lock na van: encrypted ang data habang naglalakbay.
